Game ready 'Cyberpunk 2077' weapon with a crate, knife and suppressor. Created using Maya and Substance Painter with industry techniques.

TKI-20 Shingen

By Kieran Airey

This was a project from my 2nd year at university. This project was focused on improving on hard surface modelling skills. I chose to create a weapon for the project where I decided upon the TKI-20 Shingen. With extra time towards the end of the project, I was able to create a weapon crate for the gun alongside a knife and suppressor attachment to go alongside the gun in the crate. Overall, I believe this project allowed me to improve my industry standard techniques as well as improve my eye for detail when creating 3D assets using reference images of concept art and pre-existing items. For the project I used Maya, Substance Painter and Marmoset Toolbag 5 for the rendering.
