Asylum room

By Kieran Airey

This was a personal development project where I wanted to create a small interior using skills I have developed of creating real-time game environments. I started this project by looking into the designs and layouts of old asylums. I found an image that I used as a reference online. I wanted to recreate the look of the image whilst also implementing my own style to the project which I believe I was able to achieve. This project allowed me to further develop my environment art skills and workflows within Unreal engine 5, as well as experiment with different rendered angles using the camera tools within UE5.
